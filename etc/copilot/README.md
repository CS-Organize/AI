# Copilot

| Shortcut      | Functionality                         |
| ------------- | ------------------------------------- |
| `⇥`           | Accept the suggestion                 |
| `Esc`         | Dismiss the suggestion                |
| `⌥ + \`       | Trigger Inline Suggestion             |
| `⌥ + [ [ ] ]` | Show Prev/Next Inline Suggestion      |
| `⌘ + →`       | Accept Next Word Of Inline Suggestion |
| `⌃ + ↩`       | View All Suggestion                   |
| `⌘ + I`       | Inline Chat                           |
| `⌘ + ⇧ + I`   | Open Edit with Copilot Panel          |
| `⌘ + ⌃ + I`   | Open Ask Copilot Panel                |

- /explain : Explain how the code in your active editor works
- /doc: Add documentation comment for this symbol
- /fix: Propose a fix for the problems in the selected code
- /tests: Generate unit tests for the selected code

## Instruction

`Settings`(⌘ + ,) -> Search `copilot instruction` -> Check `Github › Copilot › Chat › Code Generation: Use Instruction Files`
