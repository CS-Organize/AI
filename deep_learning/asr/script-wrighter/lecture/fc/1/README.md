# Part 1. 바이브코딩 입문 - AI로 시작하는 개발의 첫걸음

## 1.1. 누구나 개발을 할 수 있는 시대가 온다

### 1.1.1. 누구나 개발을 할 수 있다 (15분)

- 노코드/로우코드 도구의 확산
- AI의 등장
- 과거에 엑셀을 모두가 사용했던 것처럼 AI 개발을 하게된다.

### 1.1.2. 변화하는 소프트웨어 시장과 기회 (15분)

- 한국 개발 채용 시장 (잠깐)
- AI 시대의 개발 직군 변화
  - 빅테크 트렌드

### 1.1.3. 최신 AI 개발 도구 트렌드와 생태계 (15분)

- 주요 AI 개발 도구 소개
- 각 도구의 특징과 활용 분야
- 도구 선택 기준

## 1.2. AI 주도 개발이란

### 1.2.1. 전통적 개발 vs AI 주도 개발 (15분)

- 기존 개발 방식의 한계
- AI 도구를 활용한 개발의 장점
- 개발 프로세스의 변화

### 1.2.2. AI 개발 도구의 종류와 선택 기준 (15분)

- 코드 생성 AI (GitHub Copilot, Cursor 등)
- 디자인 AI (Figma AI, Lovable 등)
- 배포 및 운영 AI 도구

### 1.2.3. AI와 효과적으로 대화하는 프롬프트 엔지니어링 (15분)

- 프롬프트 작성 기본 원칙
  - OpenAI, Anthropic
- 효과적인 AI 협업 방법
