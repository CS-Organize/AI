# Part 3. 부록

## 3.1. [부록 A] 최소한의 CS 지식 - 알면 도움되는 웹 개발 상식

### 3.1.1. 웹 개발 상식 (30분)

- **프론트엔드 vs 백엔드**

  - 클라이언트-서버 모델 이해
  - 각 영역의 역할과 책임
  - 풀스택 개발의 의미

- **HTTP 프로토콜 기본**

  - HTTP 요청/응답 구조
  - GET, POST, PUT, DELETE 메소드
  - 상태 코드(200, 404, 500 등) 이해

- **데이터베이스 기본 개념**

  - 관계형 vs 비관계형 데이터베이스
  - CRUD 연산의 의미
  - 기본적인 SQL 쿼리 이해

- **API와 REST의 개념**

  - API의 정의와 필요성
  - RESTful API 설계 원칙
  - JSON 데이터 형식 이해

- **도메인과 호스팅**

  - 도메인 네임 시스템(DNS) 작동 원리
  - 웹 호스팅의 종류와 특징
  - SSL/TLS 인증서의 중요성

- **브라우저 작동 원리**
  - 렌더링 엔진과 JavaScript 엔진
  - DOM과 Virtual DOM
  - 웹페이지 로딩 과정

## 3.2. [부록 B] Git/GitHub 비개발자도 쉽게 배우기

### 3.2.1. Git/GitHub 기초 (30분)

- **버전 관리의 필요성**

  - 왜 버전 관리가 필요한가?
  - Git vs 다른 버전 관리 시스템
  - 개인/팀 프로젝트에서의 활용

- **Git 핵심 개념**

  - Repository(저장소)란?
  - Commit, Branch, Merge 이해
  - Working Directory, Staging Area, Repository

- **GitHub 기본 사용법**

  - GitHub 계정 생성 및 설정
  - Repository 생성과 관리
  - README.md 작성 가이드

- **기본 Git 명령어**

  ```bash
  git init          # 저장소 초기화
  git add .         # 모든 파일 스테이징
  git commit -m ""  # 커밋 생성
  git push          # 원격 저장소에 업로드
  git pull          # 원격 저장소에서 받아오기
  ```

- **GitHub Desktop 활용**

  - GUI 도구를 통한 쉬운 Git 사용
  - 브랜치 생성과 병합
  - 충돌 해결 방법

- **협업 워크플로우**

  - Fork와 Pull Request
  - Issue 트래킹과 프로젝트 관리
  - 코드 리뷰 프로세스

- **GitHub Pages로 무료 호스팅**
  - 정적 웹사이트 배포
  - 커스텀 도메인 연결
  - 자동 배포 설정

## 3.3. [부록 C] 바이브코딩 삽질을 줄이는 꿀팁 10가지

### 3.3.1. 바이브코딩 꿀팁 (30분)

- **꿀팁 1: 컨텍스트 엔지니어링 마스터하기**

  - AI에게 충분한 배경 정보 제공
  - 프로젝트 구조와 목표 명확히 전달
  - 이전 대화 내용 효과적으로 참조

- **꿀팁 2: 프롬프트 템플릿 활용하기**

  - 자주 사용하는 프롬프트 패턴 저장
  - 프로젝트별 커스텀 템플릿 제작
  - 단계별 작업 분해 프롬프트

- **꿀팁 3: 에러 메시지 활용법**

  - 에러 메시지를 AI에게 그대로 전달
  - 스택 트레이스 정보 포함하여 질문
  - 해결 과정도 컨텍스트로 활용

- **꿀팁 4: 코드 리뷰 요청하기**

  - AI에게 코드 품질 검토 요청
  - 보안 이슈와 성능 최적화 조언 구하기
  - 베스트 프랙티스 준수 여부 확인

- **꿀팁 5: 점진적 개발 접근법**

  - 큰 기능을 작은 단위로 분해
  - MVP부터 시작해서 단계적 확장
  - 각 단계별 테스트와 검증

- **꿀팁 6: 도구 조합 최적화**

  - Cursor + MCP + Supabase 조합 활용
  - 각 도구의 강점을 살린 워크플로우
  - 자동화 가능한 부분 최대한 활용

- **꿀팁 7: 문제 해결 패턴 학습**

  - 자주 발생하는 문제와 해결법 정리
  - 커뮤니티 활용 (Stack Overflow, Discord)
  - 공식 문서 효과적으로 읽는 법

- **꿀팁 8: 백업과 버전 관리 습관**

  - 중요한 변경 전 반드시 커밋
  - 실험적 기능은 별도 브랜치에서
  - 정기적인 백업과 배포

- **꿀팁 9: 학습 리소스 활용법**

  - YouTube 튜토리얼 효과적으로 보기
  - 공식 문서와 예제 코드 활용
  - 오픈소스 프로젝트 참고하기

- **꿀팁 10: 지속적인 학습과 실험**
  - 새로운 도구와 기술 꾸준히 탐색
  - 작은 프로젝트로 실험해보기
  - 커뮤니티와 지식 공유하기
