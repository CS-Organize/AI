# VOD 1: Cursor에서 Gemini Code 마스터하기

## 강의 개요 (Intro)

안녕하세요 대모산 개발단의 스난입니다.

혹시 '데이터만 있으면 재미있는 것을 만들 수 있을 텐데' 혹은 '나만의 웹사이트를 만들어서 다른 사람들에게 보여주면 좋을텐데' 라고 생각해보신 적 없으신가요?

이번 챌린지를 마치고 나면 그 생각들을 전부 현실로 만들 수 있습니다.
우리는 5일 동안 단순히 바이브 코딩 도구를 익히는 것을 넘어서
외부 사이트의 데이터를 가져오는 크롤링/스크래핑 기술을 배우고, 그 데이터를 시각화해주는 웹 개발 기술을 배웁니다.
'아이디어를 실제로 동작하는 서비스로 만드는' 전 과정을 압축적으로 경험하게 될 거에요.

자 그럼 시작해보겠습니다.
