## 소개

마케터 출신이 개발을 시작해서 B2B 서비스로 수익을 내고 있는 분을 초대했는데요.

### 생애

- 프로게이머
- 게임 학과 -> 프로그래밍을 배우더라
- 적성 없이 1학기 후 군대
- 전역 후 프로그래밍에 대해 거부감 -> 학교 가지 말고 일을 하자
- 제적 처리
- 알바 몇 개월
- 광고 대행사에서 마케터로 근무

### 커리어

마케터
광고 대행사

- 마케팅도 하지만 전화영업 많이했음
- 영업 사원
- 다른 대행사로 이직 -> 마케터로 근무 4년동안

이커머스

- 마케팅 팀으로 근무 1년간 근무
- 주 7일 근무 -> 스스로가 만족
  - 스스로 성취감이 중요하구나
  - 개인적인 성취감을 느낄 수 있는 일 -> 대단하다고 느낄만한 성취를 얻어보자
  - 사업

광고 대행업이 가장 쉬웠다
근데 안맞았다

남을 알려주는 것을 잘할 거 같다

직장에서 연봉을 빠른 시간 내에 올리는 전자책 -> 펀딩 100만원
교육

- 메타 광고 퍼포마
- 프리랜서 마케터로 활동
  - 이 때 해외의 A/B 테스트를 경험
  - 이거 너무 좋아서 내가 만들고 싶은데?
  - 개발 부트캠프 오프 5개월
    - 개발적인 제약 -> 캠퍼인에 대해 제약 -> 관심이 있었음
    - 해보니까 나한테 잘 맞더라
  - 개발 부트캠프 하면서 제품 만들고, 1개월 간 더 만들어서 제품을 출시했음
